# m-veiga.github.io

Site pessoal e portfólio profissional de Mateus Veiga.

O site reúne informações sobre:

- pesquisa em bioinformática estrutural;
- mecanismos moleculares da doença de Alzheimer;
- simulações de dinâmica molecular e metadinâmica;
- projetos de documentação e comunicação científica;
- desenvolvimento do PACIEnCIA;
- códigos, tutoriais e outros materiais públicos.
